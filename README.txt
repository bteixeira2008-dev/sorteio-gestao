COMO PUBLICAR NA VERCEL

1) Substitui no ficheiro index.html:
   https://formspree.io/f/SEU_ENDPOINT_AQUI
   pelo teu endpoint do Formspree.

2) Faz upload dos ficheiros para o teu repositório GitHub.

3) A Vercel atualiza automaticamente.

NO DIA DO SORTEIO
- Edita config.js
- muda publicado para true
- preenche os números vencedores

FORMULÁRIO
- Com Formspree, os dados enviados (rifa, nome, contacto, e-mail)
  ficam registados e podes responder / exportar.
